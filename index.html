Bets storage

Bets are saved, encrypted, in the private repository .

One-time setup. Create a private repository for bets (tick "Add a README file") and a token that can only reach that repository, with Contents: Read and write. Players' browsers use this token to save bets, so it must not be the admin token.

GitHub connection

Connected to . Every change made by any admin is published automatically.

One-time setup by the site owner. After this, admins only need the admin password: changes publish on their own. The token is saved encrypted with the admin password; the player password cannot open it.

Manual backup

Downloads the encrypted couples file. Only needed if GitHub is not connected: upload it to the repository to replace couples.enc.json.
